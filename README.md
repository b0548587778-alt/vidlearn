# VidLearn — סרטוני למידה, פודקאסטים, ספרי שמע וספרים

אפליקציית אנדרואיד שמחפשת **רק תוכן לימודי** — סרטונים מכמה מאגרי וידאו, ספרי שמע וספרים לקריאה — ומסדרת אותו ללימוד: קורסים, התקדמות, הערות לפי זמן.
**בלי שרת:** החיפוש רץ מהטלפון ישירות אל המקורות, וכל הנתונים (קורסים, היסטוריה, הערות) נשמרים בטלפון.

## מקורות מובנים
| מקור | איך מסונן ללמידה |
|------|------------------|
| PeerTube — Sepia Search (מאות שרתי וידאו פתוחים) | רק קטגוריית "חינוך" (13), בלי תוכן מסומן nsfw |
| Internet Archive | רק נושא/אוסף לימודי (education, lecture, course, MIT OCW…) |
| Wikimedia Commons | מאגר חינוכי; נדרשת מילת לימוד בכותרת/בתיאור |
| YouTube (כבוי עד שמתחברים / מזינים מפתח API) | קטגוריית Education (27) + SafeSearch מחמיר |

**בהגדרות אפשר להוסיף מקורות**: כל שרת PeerTube (למשל של אוניברסיטה), או שרת Invidious. רק https.

## סינון תוכן 🛡️
מעל כל המקורות:
- **רשימת מילים אסורות** מורחבת (אנגלית ועברית, + מילים שלכם) ואימוג'י לא הולמים. בכוונה בלי מילים שמופיעות בשיעורי תורה ("מיני מזונות", "סמי הקטורת", "קליפה", "רכילות"…).
- **כתיב עוקף נתפס**: אותיות מסוגננות (𝐬𝐞𝐱 / ｓｅｘ), ספרות במקום אותיות (p0rn), אותיות מופרדות (s.e.x / ס.ק.ס), ניקוד, תווים נסתרים ומילים מצונזרות בכוכבית.
- **מילות החיפוש עצמן** נבדקות — חיפוש אסור לא נשלח לאף מקור (וגם לא לוויקיפדיה).
- **סימוני המקור**: nsfw, explicit, "לא מתאים למשפחה" (יוטיוב) — נחסם.
- **"מצב מחמיר"** — מילת לימוד נדרשת בכל סרטון.
- **הסתרת תמונות** — בלי תמונות ממוזערות של סרטונים, ספרים וערכים.
- **נעילה בקוד** (4–8 ספרות): הסינון, המקורות וייבוא גיבוי לא ניתנים לשינוי בלי הקוד. נשמר רק גיבוב, והנעילה עוברת בסנכרון לכל הטלפונים של החשבון.
- גם הורדה מקישור עוברת את כל הבדיקות; אתרי מבוגרים / הימורים חסומים לפי הכתובת.

⚠ הסינון אוטומטי — הוא מצמצם מאוד, אבל אינו רואה את התמונה עצמה ולכן אינו מבטיח שכל סרטון הולם. מומלץ גם סינון אצל ספק האינטרנט.

## הורדה מיוטיוב ומקישור ⬇️
- **סרטון מיוטיוב** (מהחיפוש או מקישור) נשמר בטלפון כמו כל סרטון. יוטיוב לא נותן קובץ דרך ה-API הרשמי, לכן ההורדה עוברת דרך שרתים פתוחים של **Invidious / Piped** — שרת שלא עונה מדולג והבא מנוסה. את רשימת השרתים אפשר לשנות בהגדרות ההורדה (כתובת שמכילה `piped` נחשבת שרת Piped). לפני ההורדה הסרטון נבדק שוב בסינון.
- איכות: רגילה (עד 720p), חסכונית, או **שמע בלבד** (M4A קטן — מתאים לשיעורים).
- **הורדה מקישור** (הספרייה שלי ← שמורים בטלפון): יוטיוב (כולל youtu.be ו-shorts), Vimeo (כשיש קובץ MP4), כל שרת PeerTube, archive.org, ויקישיתוף, או קישור ישיר לקובץ MP4 / MP3 / WebM. בקובץ ישיר הסינון בודק רק את שם הקובץ והאתר.
- שימו לב: הורדה מיוטיוב עשויה להיות מנוגדת לתנאי השימוש שלו — באחריות המשתמש, ולתוכן שמותר לכם לשמור. שרתים ציבוריים עלולים להפסיק לעבוד; אז מוסיפים שרת אחר בהגדרות.

## עברית: ויקיפדיה, חיפוש דו-לשוני ויוטיוב
- **ערך מוויקיפדיה** בראש כל חיפוש: תקציר, תמונה, וקריאת הערך המלא בתוך האפליקציה (בלי הערות שוליים). ערך עם מילה אסורה לא מוצג.
- **חיפוש דו-לשוני**: במקורות הפתוחים (PeerTube, Archive, Commons, LibriVox) כמעט אין עברית. חיפוש בעברית מתורגם למונח באנגלית דרך הקישור הבין-לשוני של הערך בוויקיפדיה ("שיעור בפיזיקה" ← Physics), והתוצאות באנגלית מוצגות אחרי העברית. אפשר לכבות בהגדרות.
- **יוטיוב**: רוב סרטוני הלימוד בעברית נמצאים בו. מתחברים עם **כניסה עם Google** (או מפתח API). כשהוא כבוי — הודעה בתוצאות וכפתור כניסה. חיפוש בעברית מבקש מיוטיוב תוצאות בעברית.

## כניסה עם Google — יוטיוב וסנכרון בין מכשירים
בהגדרות ← "חשבון Google" ← **כניסה עם Google**:
- **יוטיוב** פועל עם החשבון — בלי מפתח API (מפתח שכבר הוזן ממשיך לעבוד וקודם לכניסה).
- **סנכרון**: קורסים, התקדמות, הערות, מועדפים, היסטוריה וההגדרות עוברים בין כל הטלפונים שמחוברים לאותו חשבון. הנתונים נשמרים בקובץ אחד בתיקייה הנסתרת של האפליקציה ב-Google Drive (`appDataFolder` — לא נראית ב-Drive ולא נגישה לאפליקציות אחרות). עדיין בלי שרת משלנו.
  - מסתנכרן בפתיחה, כשחוזרים לאפליקציה, כשיוצאים ממנה, וכמה שניות אחרי כל שינוי. כפתור "סנכרון עכשיו".
  - מיזוג ולא דריסה: מה שנוסף בשני הטלפונים נשמר, ההתקדמות האחרונה גוברת, ומחיקה בטלפון אחד לא "חוזרת" מהשני.
  - לא עוברים: קבצים שהורדו, הגדרות ההורדה (של כל טלפון לחוד), ומפתחות API.
- **התנתקות** מבטלת את ההרשאה בחשבון; הנתונים נשארים בטלפון. **מחיקת הנתונים מ-Drive** מוחקת גם את קובץ הסנכרון.

**הגדרה חד-פעמית ב-Google Cloud** (פעם אחת לאפליקציה, לא לכל טלפון; ההוראות גם בתוך האפליקציה):
1. [Google Cloud Console](https://console.cloud.google.com/) — פרויקט חדש (או זה של מפתח היוטיוב).
2. APIs & Services ← Library: להפעיל **YouTube Data API v3** ו-**Google Drive API**.
3. Google Auth Platform ← Branding: שם ומייל. Audience: External, והמייל שלכם ב-Test users. מומלץ **Publish app** — אחרת Google מבקש אישור מחדש כל 7 ימים.
4. Google Auth Platform ← Clients ← Create client ← **Android**: שם החבילה `com.vidlearn.app` וטביעת ה-SHA-1 של מפתח החתימה. את שניהם האפליקציה מציגה בהגדרות (עם כפתור העתקה), וה-SHA-1 מודפס גם ביומן הבנייה ב-GitHub Actions (שלב "Use the fixed signing key").
5. לא מעתיקים שום מפתח לאפליקציה: Google מזהה אותה לפי החבילה והחתימה. במסך "Google hasn't verified this app" ← Advanced ← Continue.

**אתר ומדיניות פרטיות** (נדרשים לאימות של Google): בתיקייה `docs/` — מתפרסמים ב-GitHub Pages:
https://b0548587778-alt.github.io/vidlearn/ ו-https://b0548587778-alt.github.io/vidlearn/privacy.html
(הפעלה פעם אחת: Settings ← Pages ← Branch `main`, תיקייה `/docs`.)

בלי ההגדרה הזו הכניסה נכשלת בהודעה "Google עדיין לא מכיר את האפליקציה". הכניסה עובדת רק באפליקציה המותקנת (לא ב-`npm run serve`).

## פודקאסטים 🎙️
חיפוש בספריית הפודקאסטים של Apple (בלי מפתח; חיפוש בעברית ← החנות הישראלית — עושים היסטוריה, מדע בגובה האוזניים, עושים תנ"ך…). רק קטגוריות לימודיות (חינוך, מדע, היסטוריה, טכנולוגיה, יהדות ורוחניות…), בלי קומדיה / פשע אמיתי / מוזיקה ובלי תוכן בוטה — ומעליהן סינון המילים. הפרקים מה-RSS ומתנגנים בנגן ספרי השמע: מהירות, המשך מהמקום, הערות לפי זמן, שמירת פרק בטלפון. הרשימה נשמרת ומתעדכנת ברקע.
**שירים** — לא נוספו: שירים בעברית מוגנים בזכויות יוצרים ואין להם מאגר חופשי; שירים לימודיים אפשר למצוא ביוטיוב כשהוא מחובר.

## ספרי שמע וספרים
| סוג | מקור | מה יש |
|-----|------|-------|
| 🎧 ספרי שמע | LibriVox (דרך Internet Archive) | אלפי ספרים חופשיים, בעיקר באנגלית, מוקראים בידי מתנדבים. פרקים, מהירות, ±30 שנ׳, טיימר שינה, המשך מהמקום בכל פרק, הערות לפי זמן, שמירת פרק / ספר שלם בטלפון |
| 📖 ספרים | Project Gutenberg + ספרים סרוקים מהארכיון (כולל עברית) | קורא מובנה: עמודים, החלקה, גודל גופן, סימניות, המשך מאותו עמוד, כיוון לפי השפה, שמירה בטלפון. ספר בלי טקסט — העמודים הסרוקים המקוריים |

ספרי השאלה בלבד (access-restricted) לא מוצגים, וגם לא ז'אנרים כמו רומנטיקה ואימה. מעליהם — אותו סינון מילים של הסרטונים.
**השמעה ברקע**: ספרי שמע, פודקאסטים וסרטונים ממשיכים להתנגן כשהמסך כבוי או באפליקציה אחרת — רכיב native משלנו (`native/vidlearn-native`) מפעיל בזמן ניגון שירות קדמה עם התראה "מנגן". אם טלפון מסוים עדיין עוצר: הגדרות ← סוללה ← VidLearn ← "ללא הגבלה".

## איך לומדים בה
- **מסך הבית**: תחומי לימוד, "המשך לצפות", הקורסים שלי.
- **חיפוש**: תוצאות מכל המקורות לסירוגין, סינון לפי מקור ואורך, "עוד תוצאות".
- **נגן**: כשאפשר — קובץ ישיר (Archive, PeerTube, Commons): מהירות 0.75–2×, המשך מהמקום שעצרתם, סימון "נלמד" אוטומטי ב-90%. אחרת — הנגן של המקור.
- **הערות** עם חותמת זמן — לחיצה קופצת לרגע בסרטון.
- **קורסים**: בונים מסלול משיעורים, משנים סדר, רואים התקדמות, "המשך בשיעור הבא".
- **קובץ רגיל בטלפון**: כל הורדה נשמרת גם בתיקייה `Download/VidLearn` בשם קריא (MP3 / וידאו / TXT) — רואים אותה באפליקציית הקבצים, בנגן המוזיקה ובגלריה, והיא נשארת גם אם מוחקים מהאפליקציה. אפשר לכבות בהגדרות; להורדות ישנות — כפתור 📂 במסך השמורים.
- **שמירה בטלפון לצפייה בלי אינטרנט** (Archive, Commons, PeerTube, ויוטיוב דרך Invidious / Piped): כפתור בכל סרטון, "שמירת כל הקורס", והורדה מראש של השיעור הבא בקורס. מסך "שמורים בטלפון" עם נפח ומחיקה. הגדרות: רק ב-Wi-Fi (ברירת מחדל), איכות רגילה/חסכונית, תקרת נפח, מחיקה אוטומטית של שיעור שנלמד. הורדה שנקטעה ממשיכה בפתיחה הבאה.
- עברית / אנגלית, מצב כהה, גיבוי וייבוא (JSON — בלי קבצי הווידאו).

## פיתוח
```bash
npm install
npm test              # בדיקות (node --test)
npm run serve         # http://localhost:8080 — בדיקה בדפדפן
npx cap add android && npx cap sync android   # פרויקט אנדרואיד (דורש JDK 21 + Android SDK)
```
מבנה: `www/js/sources.js` (המקורות — טהור), `filter.js` (סינון), `search.js` (חיפוש מקביל), `store.js` (נתונים בטלפון), `media.js` (ספרי שמע וספרים — טהור), `podcasts.js` (פודקאסטים ו-RSS — טהור), `links.js` (זיהוי קישורים והורדה מיוטיוב דרך Invidious / Piped — טהור), `wiki.js` (ויקיפדיה ותרגום המונח — טהור), `sync.js` (מיזוג הסנכרון וכתובות Drive — טהור), `google.js` (כניסה, טוקן וסנכרון), `downloads.js` (תור ההורדות — דרך מתאמים ל-Filesystem / Network של Capacitor), `app.js` (ממשק), `i18n.js`.
