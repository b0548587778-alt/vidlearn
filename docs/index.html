כניסה עם Google (רשות)

אפשר להשתמש באפליקציה בלי שום חשבון. מי שבוחר להיכנס עם Google מקבל שני דברים:

  • חיפוש ביוטיוב דרך YouTube API Services — הרשאת קריאה בלבד (youtube.readonly). האפליקציה לא מעלה, לא משנה ולא מוחקת דבר בחשבון היוטיוב.
  • סנכרון בין הטלפונים שלכם — הקורסים, ההתקדמות וההערות נשמרים בקובץ אחד בתיקייה הנסתרת של האפליקציה ב-Google Drive שלכם (drive.appdata). לאפליקציה אין גישה לשום קובץ אחר ב-Drive.

לאפליקציה אין שרת: הנתונים עוברים רק בין הטלפון שלכם לבין Google. פרטים מלאים במדיניות הפרטיות.

Learn from videos, audiobooks and books — educational content only

VidLearn is a free Android app that searches learning videos, audiobooks, podcasts and books from open sources and YouTube, and organizes them for study: courses, progress tracking and time-stamped notes.

Download the app (APK) Privacy Policy

Sign in with Google (optional)

The app works without any account. Users who choose to sign in with Google get:

  • YouTube search through the YouTube API Services, with read-only access (youtube.readonly). The app never uploads, changes or deletes anything in the user's YouTube account.
  • Sync between the user's own phones. Courses, progress and notes are stored in a single file in the app's hidden folder in the user's own Google Drive (drive.appdata). The app cannot see any other file in Drive.

VidLearn has no server: data only travels between the user's phone and Google. See the Privacy Policy for details.
